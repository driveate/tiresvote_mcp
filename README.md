# tiresvote_mcp

Самостоятельный MCP-сервер для каталога шин и профессиональных испытаний TiresVote.com.

**Статус: подготовка к реализации.** Репозиторий содержит согласованные требования,
архитектуру, знания об API и план работы. Исполняемого сервера и опубликованного
Python-пакета пока нет; команды установки появятся вместе с реализацией.

## Продукт

Сервер поможет найти модель шины, проверить её известные исполнения, сравнить
несколько моделей и собрать результаты испытаний с источниками.

TiresVote развивается независимо от `wheel-size-mcp`: собственный репозиторий,
пакет, процесс и релизы. Совместимость с автомобилем остаётся задачей Wheel Fitment
API. Пользователь может подключить оба MCP; общую цепочку выполняет его агент.

## Утверждённый объём первой версии

- 12 инструментов: каталог, поиск, типоразмеры, аргументы выбора, связанные материалы,
  профессиональные испытания и справочники.
- 4 сценария: подбор по известному размеру, сравнение моделей, разбор испытания,
  досье модели.
- Чтение через публичный Tires Catalog API; stdio как основной транспорт.
- Ключ `WHEELSIZE_API_KEY` — тот же, что используется для Wheel Fitment API
  (подтверждено владельцем продукта 2026-09-27).

Общий каталог статей, сторонние top charts, пользовательские отзывы отдельным
инструментом, Editorial API, текущие цены и остатки, изменения данных и собственный
алгоритм рейтинга в первую версию не входят. Связанные с конкретной шиной материалы
остаются доступны через `tires_list_materials`.

Полный список и параметры: [tools inventory](docs/tools-inventory.md).

## API и конфигурация

Публичный адрес: `https://api.wheel-size.com/v2/tires/`.
[Swagger](https://api.wheel-size.com/v2/tires/swagger/).
Планируемые переменные перечислены в [.env.example](.env.example).
Ключ передаётся upstream как query-параметр `user_key`; в ответы MCP, журналы и
сохранённые fixtures он попадать не должен.

Локальный `.env` — удобство разработчика; автоматическая загрузка dotenv пока
не предусмотрена. При реализации CLI используйте переменные процесса или настройки
окружения MCP-клиента.
